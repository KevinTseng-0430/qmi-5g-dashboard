# v0.1.0

Initial public-ready release candidate.

## Included
- SIM8200EA-M2 validated QMI collector
- 5G RSRP / RSRQ / SNR
- PLMN / RAT / registration / roaming
- APN / IP / gateway / DNS / MTU
- RX/TX rate from Linux counters
- FastAPI REST API
- WebSocket live updates
- browser dashboard
- systemd examples
- setup and troubleshooting docs

## Known limitations
- no band / Cell ID / NR-ARFCN yet
- no persistent time-series database
- no multi-modem support
- no authentication; use only on trusted networks
